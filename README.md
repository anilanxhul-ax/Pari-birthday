# 🎂 Happy Birthday Pari — GitHub Pages

A premium, mobile-friendly birthday surprise website made for Pari.

## 1. Put your photos
Create a folder named `photos` and add:
- photo1.jpg
- photo2.jpg
- photo3.jpg
- photo4.jpg
- photo5.jpg
- photo6.jpg

Then replace the six `.photo` placeholder `<div>` elements in `index.html` with `<img src="photos/photo1.jpg">` etc.

## 2. Add music
Create a folder named `music` and put your MP3 there as:
`music/birthday.mp3`

The website has a Play Music button because browsers commonly block autoplay.

## 3. Publish with GitHub Pages
1. Create/sign in to GitHub.
2. Create a new repository, e.g. `pari-birthday`.
3. Upload `index.html`, `style.css`, `script.js`, plus your `photos` and `music` folders.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. GitHub will provide your website link.

## 4. Important
Do not upload private information or photos you do not have permission to share publicly. If the repository is public, anyone with the link may be able to view the files.
